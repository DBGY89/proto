Block 01 — Build & Publish 03

Build with an AI coding assistant + GitHub + GitHub Pages

From a prompt to a live URL. By the end of this SOP you have a URL.

Your AI coding assistant writes the code. GitHub stores it. GitHub Pages publishes it. At the end of this SOP you will have a real URL you can share with anyone. Free.

Seeing your project live for the first time is genuinely exciting. It is also just the beginning.

GitHub Pages is the right first choice here. Zero configuration, zero cost, and it forces you to keep the project simple enough to be a static site, which is exactly right for a first version. The constraint is a feature. You can always migrate to Vercel later when your project genuinely needs it.

1
Create a GitHub account and a new repository
Go to github.com, sign up if needed. Click "+" and "New repository." Name it, set it to public, check "Add a README file," click "Create repository."
2
Open your AI coding assistant and paste your PRD
Start a new session. Paste your PRD from SOP 01. Write your prompt: role, context, task, constraint. Ask it to build your landing page as a single HTML file.
3
Make it yours
Look at what the AI built. This is your first draft. Now tell it exactly how you want it to look. Be specific. "Make it more minimal." "Use a dark background." "Make the typography bigger and bolder." "Make it look like a 90s zine." The AI will follow. Iterate until it feels like you.
4
Save the output as index.html and open it in your browser
Copy the code the AI generated. Save it as index.html. Open that file in your browser. If something looks wrong, describe it to your AI assistant and iterate.
5
Upload the file to GitHub
Go to your repository on GitHub. Click "Add file" then "Upload files." Drag your index.html in. Add a commit message like "first version" and click "Commit changes."
6
Enable GitHub Pages
In your repository go to Settings, then Pages in the left sidebar. Under Source, select "Deploy from a branch." Choose main branch and / (root). Click Save. Wait one minute.
7
Open your live URL
Refresh the Pages settings page. Your URL appears in the format yourusername.github.io/your-repo-name. Click it. Your page is live on the internet.
Your task this week SOP 03
Get your landing page live on a real URL.

Take your prompt from SOP 02, open your AI coding assistant, and build the first version of your landing page. Make it yours. Push it to GitHub. Enable GitHub Pages. Do not wait until it is perfect. Get it live first.

When done A live URL with your landing page on it. Something real, on the internet, that anyone can visit.
