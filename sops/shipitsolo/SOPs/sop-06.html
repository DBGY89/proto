Block 01 — Build & Publish 06

Vercel — deploy with your own URL

Automatic deploys, a free custom domain, and support for projects that go beyond static HTML. Still free for everything in this bundle.

GitHub Pages is excellent for static projects. Vercel does everything GitHub Pages does, and more: automatic deploys every time you push code, environment variables managed securely through a dashboard, and preview deployments for every branch.

Vercel gives you infrastructure that used to cost thousands of dollars a month. For free. For personal projects.

Switch from GitHub Pages to Vercel when your project needs automatic deploys or when you add a backend function that cannot live in the browser. Until then, GitHub Pages is fine.

What this costs

The free Hobby plan covers everything in this bundle. Unlimited personal projects, automatic HTTPS, custom domains, generous bandwidth.
Free tier is enough
1
Create a Vercel account
Go to vercel.com and sign up with your GitHub account. This lets Vercel access your repositories and deploy automatically when you push code.
2
Import your GitHub repository
From the Vercel dashboard, click "Add New" then "Project." Select your repository. Vercel detects the project type automatically.
3
Deploy
Click "Deploy." About one minute later you get a URL on vercel.app. From now on, every push to GitHub triggers an automatic redeploy.
4
Add your custom domain (optional)
In project settings go to "Domains." Type your domain. Vercel shows you the DNS records to add. Vercel handles HTTPS automatically.
